Grammar: some / any & would like

Yemek ve içecekten söz et, kafede kibarca sipariş ver. (Talk about food and drink, and order politely at a café.)

Selam, ben Gri. Bu ünitede yemekten söz ediyoruz. Olumlu cümlelerde some, soru ve olumsuzlarda any kullanırız: "There is some juice." ve "Are there any sandwiches?" Kafede kibarca sipariş verirken de would like kalıbı var: "I would like a burger." Hadi menüye bakalım.

Dinleme (Listening)

Ne Demek? (some / any & would like)

some ve any "biraz / hiç" anlamındadır ve yemek-içecek anlatırken çok kullanılır. Kafede kibarca istemek için de would like (isterim) kalıbını kullanırız. Hangisini seçeceğin cümlenin türüne bağlıdır:

  • There is some juice in the fridge.Buzdolabında biraz meyve suyu var. (olumlu → some)
  • Are there any sandwiches?Hiç sandviç var mı? (soru → any)
  • I would like a burger, please.Bir burger istiyorum, lütfen. (kibar istek)
Kolay yol
  • Olumlu cümle → some. Soru ve olumsuz → any.
  • İkram ederken de some: "Would you like some tea?"

1. some / any (Hangi Cümlede Hangisi?)

Doğru kelimeyi seçmek için önce cümlenin türüne bak. Bu tablo hepsini gösterir; menü ve kafe bağlamıyla kullan:

Cümle türüKelimeÖrnek
Olumlu (+)someThere is some milk in the glass.
Soru (?)anyAre there any eggs?
Olumsuz (−)anyThere isn't any bread.
İkram / isteksomeWould you like some cake?
Kolay yol
  • Olumlu → some. Soru ve olumsuz → any.
  • "There is any milk" ✗ → "There is some milk" ✓ (olumlu → some).

2. Sayılabilir / Sayılamaz (Countable / Uncountable)

Bazı yiyecekleri sayabiliriz (an apple, two eggs), bazılarını sayamayız (water, rice, bread). Bu, hangi kelimeyi seçtiğini etkiler:

TürÖrnekKullanım
Sayılabilir tekila sandwich, an applea / an
Sayılabilir çoğulsome sandwichessome / any · how many
Sayılamazsome water, some ricesome / any · how much
Kolay yol
  • Sayılabilir çoğul → how many (how many apples). Sayılamaz → how much (how much water).
  • Tekil sayılabilir kelimeyle a / an kullan: a burger, an orange.

3. would like (Kibarca İstemek)

Kafede ya da masada bir şey isterken want yerine daha kibar olan would like kullanırız. Sonrasına bir isim gelir:

YapıKullanımÖrnek
I would like ...isterimI would like a chicken burger.
Would you like ...?ister misin?Would you like some tea?
Kolay yol
  • would like'tan sonra isim gelir: a coffee, some water, an apple.
  • İkram ederken some kullan: "Would you like some dessert?"

4. a / an (Sayılabilir Tekil)

Tek bir sayılabilir yiyecekten söz ederken a ya da an kullanırız. Seçim, sonraki kelimenin ilk sesine bağlıdır:

Kelimea / anNeden?
a burgerasessiz harf (b).
an appleansesli harf (a).
an orangeansesli harf (o).
a sandwichasessiz harf (s).
Kolay yol
  • Sesli harfle (a, e, i, o, u) başlayan kelimeden önce an, diğerlerinde a.
  • "a apple" ✗ → "an apple" ✓.

5. Sık Yapılan Hatalar (Common Mistakes)

some, any ve would like'ı karıştırmak kolaydır. Bu tabloyu bir kontrol listesi gibi kullan:

Yanlış ✗Doğru ✓Neden?
There is any milk.There is some milk.olumlu → some.
Are there some eggs?Are there any eggs?soru → any.
I would like water.I would like some water.istekte some + isim.
How much apples?How many apples?apples sayılabilir → many.
I would like a apple.I would like an apple.sesli harf → an.
Altın kural
  • Önce cümleye bak: olumlu → some, soru/olumsuz → any. Sayılabilir çoğul → how many, sayılamaz → how much. Kibar istek için would like + isim; ikramda some.

6. Birlikte Görelim (At the Café)

Garson ve bir genç sipariş konuşuyor. Koyu yazılan some / any / would like biçimlerine dikkat et ve iki kez oku:

  • — Would you like to order?Sipariş vermek ister misin?
  • — Yes, please. I would like a cheese sandwich and some juice.Evet, lütfen. Bir peynirli sandviç ve biraz meyve suyu istiyorum.
  • — Would you like any dessert?Tatlı ister misin?
  • — Is there any chocolate cake?Hiç çikolatalı kek var mı?
  • — Yes, there is some cake, but there aren't any cookies today.Evet, biraz kek var, ama bugün hiç kurabiye yok.
  • — OK, I would like a piece of cake, please.Tamam, bir dilim kek istiyorum, lütfen.
Sık yapılan hatalar
  • "Is there some cake?" ✗ → "Is there any cake?" ✓ (soru → any).
  • "I would like juice" ✗ → "I would like some juice" ✓.
  • "a orange" ✗ → "an orange" ✓ (sesli harf → an).

Alıştırma (Practice)

Doğru cevabı seç. — 10 soru, her soru hemen kontrol edilir.

Your Turn (Senin Sıran)

Talk about a café you like or order a meal. Write 5 sentences with some / any / would like. (Sevdiğin bir kafeyi anlat ya da bir yemek sipariş et. some / any / would like ile 5 cümle yaz.)

Kurallar
  • Olumlu cümlede → some (There is some ...). Soru ve olumsuzda → any (Is there any ...?).
  • En az bir would like cümlesi ve bir sayılabilir/sayılamaz örneği (a sandwich / some water) kullan.

Cümle başlatıcıları (istersen bunlarla başla):

"I would like ..." "There is some ..." "Are there any ...?" "Would you like ...?" "There aren't any ..."
Sample Answer 1. I usually go to a small café near my school.
2. I would like a cheese sandwich and some orange juice.
3. There are some fresh cakes, but there aren't any cookies today.
4. "Would you like some tea?" the waiter asks me.
5. The food is tasty, so it is my favourite place!

Reading: Lunch at the Corner Café

Metni oku, sonra soruları cevapla. (Read the text, then answer.)

Before You Read (Okumadan Önce)

Okumadan önce şu yapıları hatırla — Speaking bölümünden tanıyorsun. Metinde bunları ara:

some · any · would like · a / an · how much · how many

İpucu
  • Metin bir gencin kafede öğle yemeğini anlatıyor: menü, sipariş, tatlı, hesap. some / any ve would like biçimlerine dikkat et.
  • Önce hızlıca oku, sonra soruları oku ve cevapları metinde ara. Cevaplar hep metnin içindedir.
Lunch at the Corner Café

Hi! I am Ekin and I am fifteen. Every Saturday, my friends and I go to the Corner Café near the park. It is a small, busy place, and the food there is really tasty. Usually four of us meet for lunch.

My best friends are Deniz, Ali and Su. We are all in the same class at school. The café is not far from the park. We walk there together after our morning classes. The walk is short and easy. We talk and laugh on the way. Sometimes we play music on my phone. I like Saturdays a lot because I see my friends. Lunch at the café is my favourite time of the week. The café is always open at lunchtime, so we never wait outside.

First, I look at the menu. There are a lot of sandwiches, and there is some fresh soup too. I don't eat meat, so I always choose the cheese sandwich. My friend Deniz likes a chicken burger with some chips. The waiter comes to our table and asks, "Would you like a drink?" I say, "Yes, please. I would like some orange juice." Deniz asks for a glass of water because he isn't very thirsty.

There are many things on the menu. There is some soup, there are some salads, and there are a lot of sandwiches. Su likes a tomato sandwich with some cheese. Ali would like a big burger and some water. I read the menu slowly because I want a good lunch. The prices are small, so we are all happy. We are very hungry and we want to eat soon. The waiter writes our order in his little book. Then he goes to the kitchen with a smile.

The waiter is friendly. "Do you want any dessert?" he asks. There is some chocolate cake on the counter, and it looks amazing. "How much is the cake?" I ask. It isn't expensive, so we order two pieces. Today there aren't any cookies, but the cake is enough for us.

The chocolate cake is big and brown. It has some cream on the top. Su wants some cake too, so she orders one piece. Ali doesn't want any cake today. He would like some ice cream, but there isn't any ice cream now. That is fine for him. He drinks some cold water and he is happy. We wait for our food and we talk about school. We talk about our homework, our teachers and the weekend.

The café isn't quiet, but it is fun. There is some soft music, and there are many students at the other tables. Our food comes quickly. My sandwich is fresh and the juice is cold. Deniz says his burger is great, but there aren't enough chips on the plate!

Our food is always fresh and hot. My cheese sandwich has some bread, some cheese and a little butter. It is small but it is very tasty. Deniz eats his burger quickly because he is hungry. Su eats her sandwich slowly and she drinks some juice. We share our chips and we laugh a lot. The café is a happy place for us. We take some photos of our food for fun.

I like this café because it is warm and friendly. There are some pictures on the walls. There is a small green plant on every table. The waiter smiles at us and he is very kind. Some students do their homework at the tables. Other students eat sandwiches and drink juice. A few people read books in the corner. The music is soft and nice. I feel happy here with my good friends.

At the end, we ask for the bill. "Would you like anything else?" the waiter says. "No, thank you. Just the bill, please," I answer. The lunch isn't cheap, but it isn't too expensive either. We don't have much money, so we share the bill.

We are not rich, so we always share the money. Each friend puts some coins on the table. It is easy and it is fair. We count the money together and it is enough. We say "thank you" to the friendly waiter. He says, "See you next Saturday!" We put on our coats and we go outside. The sun is warm and the park is green. We walk home slowly and we feel happy. It is a very good day for all of us.

The Corner Café is our favourite place. The people are kind, the food is tasty, and there is always some good music. Would you like to come with us next Saturday?

Writing: At the Café

Sevdiğin bir kafeyi ya da yemeği anlat ve gönder; öğretmenin okuyacak. (Describe a café or a meal; your teacher will read it.)

Küçük Bağlaçlar (Small Words: and, but, because, so)

İki fikri birbirine bağlamak için küçük bağlaçlar kullanırız. Cümlelerini bunlarla birleştir:

BağlaçAnlamıÖrnek
andveI would like a sandwich and some juice.
butamaThere is some cake, but there aren't any cookies.
becauseçünküI choose water because I am not thirsty.
sobu yüzdenThe food is tasty, so it is my favourite café.
İpucu
  • Yazında en az 1 bağlaç kullanmayı dene: and, but, because ya da so.

Task (Görev)

Describe a café you like or a meal you order: what is on the menu, what you would like and how the food is. (Sevdiğin bir kafeyi ya da verdiğin bir siparişi anlat: menüde ne var, ne istersin ve yemek nasıl.) 4-6 cümle yeterli.

NELER OLMALI (What to include)

  • one sentence with some (There is some ... / I would like some ...)
  • one sentence with any (Is there any ...? / There aren't any ...)
  • one "would like" sentence (I would like ...)
  • one countable/uncountable example (a sandwich / some water)
  • one connector: and / but / because / so

ÖRNEK BAŞLANGIÇLAR (Example openers)

"My favourite café is ..." "I would like ..." "There is some ..., but ..."
