YDT — Conditionals

YDT sınavının koşul cümleleri sorularına odaklanan 50 cümle tamamlama sorusu. Type 0, Type 1, Type 2, Type 3 ve Mixed Conditionals yapılarının yanı sıra Inversions (Had I known, Were I, Should you), Unless / Provided that / As long as / In case, Wish ve If only kalıpları, Without ve But for ile imalı (implied) koşul yapılarını kapsar. Her sorunun ayrıntılı Türkçe açıklaması ile öğrenci yapıların farklarını netleştirir.

İnteraktif Dijital Materyal
Satın Al

Ödeme onaylandıktan sonra giriş bilgileri (kullanıcı adı ve şifre) e-posta ile gönderilir. Materyale tarayıcıdan erişilir, indirme gerekmez.

İçindekiler

Bu pakette neler var

  • 50 cümle tamamlama sorusu, YDT sınav formatında
  • Type 0/1/2/3, Mixed Conditionals (her iki yön), Inversions (Had I known, Were I, Should you), Unless, Provided that, As long as, In case, Suppose, Wish ve If only, Implied Conditionals (Without, But for, Had it not been for)
  • Akademik İngilizce bağlamı (bilim, çevre, tarih, sağlık, kültür)
  • Doğru cevap dağılımı dengeli (A, B, C, D, E şıkları eşit ağırlıkta)
  • Her sorunun ayrıntılı Türkçe açıklaması
  • Test bittikten sonra soru soru analiz ekranı
  • İnteraktif arayüz, otomatik puanlama, yüzde gösterimi
  • Boş bırakılan soruların ayrıştırılması
Kimler İçin

Hedef Kitle

YDT sınavına hazırlanan, koşul cümlelerinin farklı tiplerini ayırt etmekte zorlanan veya Mixed Conditionals, Inversions, Wish gibi ileri yapıları sınav perspektifinden derinlemesine çalışmak isteyen öğrenciler için uygundur.
