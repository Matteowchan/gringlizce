Zero & First ConditionalKoşul: Type 0 & 1

Türkçedeki "-se/-sa" koşul ekine yakındır; Type 0 genel doğru/bilimsel gerçek, Type 1 ise gerçek ve olası gelecek koşuludur.

It is close to the Turkish conditional suffix "-se/-sa"; Type 0 states a general truth or scientific fact, while Type 1 states a real and likely future condition.

İngilizce koşul cümlelerinin ilk iki basamağı: Zero Conditional (Type 0) her zaman doğru olan genel gerçekleri ve bilimsel kuralları anlatır — If you heat ice, it melts. First Conditional (Type 1) ise gerçek, olası ve genellikle gelecekteki bir koşul ile onun sonucunu bağlar — If it rains, we will stay home. Her ikisinde de if cümleciği (koşul) present zamandadır; sonuç Type 0'da yine present, Type 1'de ise will + fiil ya da başka bir gelecek/emir yapısındadır. Bu sayfa iki yapının kuruluşunu, anlam farkını, Türkçe "-se/-sa" ile ilişkisini, if / when / unless / as long as gibi bağlaçları ve Türk öğrencilerin en sık yaptığı hataları derinlemesine işler. Sonraki basamak — hayali/olasılığı düşük koşullar — için bkz. Koşul: Type 2.

The first two steps of English conditional sentences: the Zero Conditional (Type 0) describes general truths that are always true and scientific rules — If you heat ice, it melts. The First Conditional (Type 1) links a real, likely and usually future condition to its result — If it rains, we will stay home. In both, the if clause (the condition) is in the present; the result is again present in Type 0, while in Type 1 it takes will + verb or another future/imperative structure. This page explores in depth how the two structures are built, the difference in meaning, their relationship with the Turkish "-se/-sa", conjunctions such as if / when / unless / as long as, and the mistakes Turkish learners make most often. For the next step — imaginary/unlikely conditions — see Conditionals: Type 2.

Conditional sentences (conditionals) combine a condition and the result that appears if that condition is met in a single sentence. In Turkish we do this with the "-se/-sa" suffix: "Yağmur yağarsa evde kalırız." English does the same job with the conjunction if. On this page you will learn the two most realistic steps of the conditional: truths that are always true (Zero Conditional) and situations that are likely to happen in the future (First Conditional).

Zero (Type 0)
An always-true fact / rule: If you heat ice, it melts. — present + present
↔
First (Type 1)
A likely future situation: If it rains, we will stay home. — present + will

Why does it exist? Because life constantly works on the logic of "if... then...". Whether we are explaining a rule ("If you boil water at 100 degrees, it turns to steam"), making a plan ("If I get stuck in traffic, I'll call you"), or giving a warning ("If we don't hurry, we'll be late"), we always use this structure. Without conditional sentences, it is almost impossible to make plans about the future, explain rules, or negotiate.

The Turkish equivalent. The "-se/-sa" suffix is very close to the English if, and that is good news. But there is a trap: in Turkish we usually state the result with the future tense ("gelirsen görürsün"), whereas in English you never use will in the conditional clause — will comes only in the result part. This is Turkish learners' biggest trap, and we will return to it many times on this page.

Most common mistake

will is not used in the if clause. Correct: If it rains, I will stay. Wrong: If it will rain, I will stay.

Why does it feel hard? For three reasons: (1) Turkish logic pushes you to build "if + will"; (2) the fine differences between if and when, and between unless and if not, get confused; (3) the conditional clause can come first or last and the comma rule changes. Once you resolve these three clearly, conditional sentences become extremely logical and easy. For the building blocks, keep the Present Simple and Future (will / going to) topics close at hand as well.

Type 0 ile Type 1'i tek soruyla ayır: "Her zaman mı doğru (ALWAYS), yoksa sadece bu sefer mi (THIS TIME)?" ALWAYS → iki taraf present (Type 0). THIS TIME → present + will (Type 1). Görselleştir: Type 0 bir kanun kitabı (değişmez), Type 1 bir hava durumu tahmini (bu seferlik).
Püf Noktası: unless = if...not

Tips & Tricks: Virgül konum kuralı
Koşul baştaysa virgül var, sondaysa yok. Hatırlama: "If başta, virgül şart." If it rains, I'll stay. (virgül) ↔ I'll stay if it rains. (virgülsüz). Yazılı sınavda bu tek virgül puan kurtarır.

Türk öğrencilerin bir numaralı hatası: koşul cümleciğine will koymak ("If it will rain..."). Türkçe "yağacaksa/yağarsa" gelecek çağrışımı yaptığı için beyin will'i oraya iter. Bu refleksi kırmak için önce hep şunu de: if → present.
Memory Aid: the 'if + will forbidden' rule
A rhyming shortcut: "after 'if' there's no 'will'; in the result, feel free." After conditional-time conjunctions such as if / when / unless / as long as, the verb stays present. Rule of thumb: if you look at a sentence and see will right next to the word if, it is 99% a mistake (except for the request exception).
Memory Aid: 'ALWAYS or THIS TIME?'
Separate Type 0 and Type 1 with one question: "Is it always true (ALWAYS), or just this time (THIS TIME)?" ALWAYS → both sides present (Type 0). THIS TIME → present + will (Type 1). Picture it: Type 0 is a law book (unchanging), Type 1 is a weather forecast (just this once).
Tip: unless = if...not
When you see unless, read it in your mind as "if...not". "Unless you hurry" = "If you don't hurry". That is why you don't put a second not/don't inside unless — it is already negative. Shortcut: unless already carries the "not" inside it.
Tips & Tricks: The comma position rule
If the condition is first, there is a comma; if it is last, there isn't. Reminder: "If first, comma required." If it rains, I'll stay. (comma) ↔ I'll stay if it rains. (no comma). In a written exam this single comma saves marks.
The single most common mistake
Turkish learners' number-one mistake: putting will in the conditional clause ("If it will rain..."). Because the Turkish "yağacaksa/yağarsa" carries a future connotation, the brain pushes will there. To break this reflex, always say this first: if → present.

Concept check Answer the question for each sentence.

  4. "Unless you study, you'll fail." — What happens if the student studies?

    'might' shows low probability (maybe), 'will' shows the speaker is sure (you'll definitely catch it).
  6. "Take an umbrella in case it rains." — Is it raining now, or is it certain to rain?
    Neither; a precaution is being taken AGAINST THE POSSIBILITY of rain. 'in case' states a precaution, not a condition.
